What is measured

Public cumulative counters for views (impressions), likes, reposts, replies, quotes, and bookmarks are collected once daily. Day labels use America/Chicago. Values are observed counters, not unique people.

Growth curves sum values returned on each date. Cohort additions and missing observations can change these totals. Net-change charts use only the same posts observed on consecutive Chicago dates; decreases remain visible as counter corrections.

What the graph establishes

An edge requires an API-verified immediate parent. Direct reposts, quotes, quotes of quotes, and reposts of quotes remain distinguishable. Cumulative counters may exceed the number of discoverable event IDs.

The observed network is a lower bound. Repeated event retrieval is not new diffusion. Creation-date views describe when events occurred; first-observed views describe when collection discovered them.

Cohort & follow-up

The six-account study preserves its baseline and admits additional originals only for accounts below two. Eligible posts were new in the completed Chicago collection window; a midnight first observation can fall on the next calendar date.

Roots can enter checkpoint-only collection after two consecutive zero-change daily intervals. Day-30, day-60, and day-90 observations remain required. Changed checkpoints reactivate daily collection.

Research questions

RQ1 describes engagement timing and persistence. RQ2 compares message and account characteristics. RQ3 examines observed diffusion. RQ4 tests prediction at 30, 60, and 90 days when outcomes mature.

Forecast training uses earlier-created posts and testing uses later-created posts, keeping each post in one partition. Current short follow-up and small sample sizes do not support strong predictive or causal claims.

Public export

Only curated daily metrics, FDA post summaries, coded themes, and anonymous downstream nodes are published. API payloads, database backups, credentials, and downstream authors' text and handles remain outside this repository.

Observation status

Missing API responses remain missing. Charts never convert absent metrics to zero or carry earlier values into a later collection date. A gap in collection is not evidence that engagement stopped.
